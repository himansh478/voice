# PYTHON — The Name Behind the Language

A premium vertical technology documentary explaining the narration’s central reveal: **Python’s name comes from Monty Python’s Flying Circus, not from a snake.** The story moves from the misconception to 1989, Guido van Rossum, a Christmas hobby project, the comedy-show namesake, and Python’s modern ecosystem.

## Audio and authenticity

The original MP3 is never re-recorded, replaced, rewritten or regenerated. The locally synthesized score and 37 restrained sound events sit below the voice. Raw Whisper passes and pause analysis are retained in `subtitles/` and `audio/analysis/` for transparency. The final transcript only normalizes obvious ASR spelling/proper nouns while retaining the narration’s meaning and sequence.

All visuals are original SVG, CSS and Three.js graphics. No unrelated stock footage, template reel, external AI-video claim, or remote render-time asset is involved.

See **`source-project/README.md`** for Windows instructions, source maps, render commands, optional Whisper regeneration and audio rebuilding. The video can be edited and rendered without Python because all curated timing data and master audio are included.
