# Original Visual Assets

- `python-mark.svg`: original two-colour Python-inspired vector mark.
- `snake-line.svg`: original line-art serpent used for the opening misconception.
- `../source-project/src/components/Graphics.tsx`: editable animated SVG versions of these assets plus the neural-network, AI-chip and robot-arm infographics.
- `../source-project/src/scenes/`: editable theatre, winter desk, timeline, researcher card, typography and transition artwork.

All visual assets were created locally with SVG/CSS/Three.js. No external stock footage, template packages, random PNGs or unconfigured AI-video services were used.
